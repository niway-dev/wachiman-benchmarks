👮 **Wachiman** · 🟡🐛 **Consider · bug: Double-clicking a name to select it still toggles the row once (confidence medium)**

The guard reads the selection when the click arrives, so it covers a drag-select. A double-click does not get the same treatment. Its first `click` comes before any selection exists, so it toggles the row. Chromium selects the word on the second mousedown, so only the second click is skipped. The row ends up flipped, which is the same side effect the earlier thread described, just reached by double-click (and triple-click) instead of drag. It does show on screen as a dimmed row and a changed summary. One option is to toggle only on `event.detail === 1` and undo the toggle when `event.detail === 2` and a selection exists. Another is to make only the non-text parts of the row (padding, icon, arrow) the toggle target. If double-click copying isn't a use case you care about, leave it as is.
